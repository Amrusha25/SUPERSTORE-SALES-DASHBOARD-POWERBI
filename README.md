# 🛒 Superstore Sales Analysis – Power BI

## 📊 Project Overview
An interactive Power BI dashboard developed to analyze Superstore sales, profit, orders, customers, and product performance.

## 🎯 Project Objectives
- Analyze sales and profit performance.
- Track orders, customers, and products.
- Compare regional and category performance.
- Identify important sales and profit trends.

## 📊 KPIs Used
- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Total Products

## 🔍 Key Insights
- Sales and profit by region.
- Sales by product category.
- Profit performance across categories.
- Top-performing products.
- Regional performance.
- Sales trends over time.

## 🛠️ Tools Used
**Power BI | Power Query | DAX**

## 📌 Conclusion

The Superstore Sales Analysis project transforms raw sales data into an interactive Power BI dashboard. It provides a clear view of sales, profit, orders, customers, and product performance through KPIs, DAX measures, filters, and visualizations. The dashboard helps identify key trends, compare regional and category performance, and support data-driven business analysis.
